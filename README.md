# ETF 行情日报

每个交易日收盘后自动生成的全市场 A 股 ETF 行情分析报告，以静态网页形式发布。

**在线浏览**：https://knightzz1998.github.io/etf-daily-report/

## 内容

| 章节 | 说明 |
|---|---|
| 一、今日结论 | 市场档位（熊市 / 牛市启动 / 牛市确认）与仓位上限 |
| 二、指数位置 | 上证、创业板相对 MA20 / MA60 / MA120 的距离与 MA60 方向 |
| 三、涨跌分布 | 按资产类型（宽基 / 行业主题 / 跨境 / 商品 / 货币）统计涨跌家数 |
| 四、赛道强弱 | 同赛道基金聚合后的领涨、领跌排行 |
| 五、策略信号 | 第一买点、周线 J 超买、离场信号名单 |
| 六、全量明细 | 全部标的的均线、周线 J、涨跌幅，按距 MA20 由远到近排序 |

## 档位规则

只在牛市启动初期参与，熊市不开新仓：

- **熊市**：上证未满足「收盘 > MA60 且 MA60 上行 且 MA20 > MA60」→ 总仓 0%，只做持仓管理
- **牛市启动**：上证满足三重确认 → 单只 ≤15%，最多 3 只，总仓 ≤45%
- **牛市确认**：上证与创业板均满足 → 单只 ≤20%，最多 5 只，总仓 ≤80%

## 指标口径

- 周线 KDJ(9,3,3)：近 6 周 J 谷底 ≤ 20 且本周 J 回勾为凹底条件
- 均线：MA5 / MA17 / MA20 / MA60，简单移动平均
- 第一买点：周线 J 凹底回勾 + 现价站上 MA17 + MA5 在 MA17 上方
- 离场：收盘跌破 MA17

## 数据来源

| 用途 | 数据源 |
|---|---|
| 全市场 ETF 快照 | 腾讯 `qt.gtimg.cn`；东财可用时优先东财 |
| 日线历史 | 东财 `push2his` / 新浪 |
| 指数日线 | 同上 |

数据源不可用时报告顶部会标注降级状态与缺失字段，不静默使用替代数据。
